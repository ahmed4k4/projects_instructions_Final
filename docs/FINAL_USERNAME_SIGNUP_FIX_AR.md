# تقرير الإصلاح النهائي — Nexus PC Builder

## المشاكل التي تم إصلاحها

1. **TypeScript `TS2339` في `api/auth/signup.ts`:** النسخة السابقة من ملف ZIP كانت ما زالت تحتوي على `admin.auth.admin.createUser`، وهو الاستدعاء الذي فشل في بيئة البناء لديك. النسخة الحالية تستخدم طلبًا خادميًا مباشرًا إلى Supabase Auth Admin REST API (`POST /auth/v1/admin/users`) مع `email_confirm: true`، ولا تحتوي على `auth.admin.createUser` إطلاقًا. يظل `SUPABASE_SERVICE_ROLE_KEY` على الخادم فقط.
2. **خطأ HTML pattern في المتصفح:** تم تهريب الشرطة `-` داخل Character Class (`\\-`) حتى يكون النمط صالحًا مع Regular Expression بوضع `v` المستخدم في المتصفحات الحديثة، مع الاحتفاظ بدعم أسماء المستخدمين التي تحتوي على `-` و`_` و`.`.
3. **رسالة فشل إنشاء الحساب:** مسار التسجيل يعيد رسائل عربية مناسبة للأخطاء المعروفة، ويطبع تفاصيل Supabase في سجل الخادم فقط دون كشف المفتاح السري أو تفاصيل حساسة للمتصفح. يجب أن تكون متغيرات Supabase وMigration 015 مضبوطة كما هو موضح أدناه.

## حدود التحقق

لم يتم تشغيل `pnpm typecheck` أو `pnpm build` كاملين؛ مجلد `node_modules` غير موجود في بيئة تجهيز النسخة، ولا يمكن اعتبار فحص transpile المستقل بديلًا عن build كامل. كما لم يتم اختبار إنشاء حساب حقيقي على مشروع Supabase الخاص بك لعدم توفر مفاتيح المشروع. لذلك لا أدّعي أن اختبارًا حيًا على Supabase أو Vercel قد تم.

## خطوات النشر المطلوبة

1. فك ضغط النسخة الجديدة وارفع محتويات مجلد `nexus-fix` إلى المستودع بدل النسخة السابقة.
2. في Vercel أضف `SUPABASE_SERVICE_ROLE_KEY` كمتغير بيئة **سري خادمي**، من دون بادئة `VITE_`.
3. تأكد من وجود `SUPABASE_URL` أو `VITE_SUPABASE_URL`، ومن متغيرات Supabase العامة المستخدمة من الواجهة.
4. نفّذ `supabase/migrations/015_username_signup_rate_limit.sql` في مشروع Supabase.
5. أعد النشر على Vercel، ثم جرّب اسم مستخدم جديدًا وكلمة مرور لا تقل عن 8 أحرف.

## ملاحظات أمان وتشغيل

- لا تضع `SUPABASE_SERVICE_ROLE_KEY` في كود المتصفح أو Git أو متغير يبدأ بـ `VITE_`.
- الحسابات الجديدة تستخدم اسم المستخدم وكلمة المرور، مع بريد اصطناعي داخلي ينتهي بـ `.invalid` ولا يستقبل رسائل.
- لا توجد استعادة كلمة مرور عبر البريد لهذه الحسابات؛ يجب الاحتفاظ بكلمة المرور أو بناء مسار استعادة منفصل.
- الموقع والـ AI يظلان متاحين كضيف. حدود استخدام AI مستقلة عن حد إنشاء الحسابات، وكلاهما لا يغيّر حصص Google Gemini على مستوى المشروع.
- أخطاء `Cently` و`Shortcut` و`127.0.0.1:5500` الظاهرة في Console ليست جزءًا من endpoint التسجيل؛ تبدو صادرة من إضافات المتصفح أو Live Server. خطأ `THREE.WebGLRenderer: Context Lost` يخص WebGL/مشهد 3D ويحتاج فحصًا منفصلًا إذا كان يتكرر داخل الموقع بعد تعطيل الإضافات.
